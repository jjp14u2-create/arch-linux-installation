# Publishing and submitting

1. Review `index.md` and remove or correct anything you did not personally complete. Add actual VM CPU/RAM settings if required. Do not include passwords or private account information.
2. Sign in to https://github.com and create a new **public** repository named `arch-linux-installation`.
3. Upload `index.md`, `_config.yml`, and `README.md` into the repository's root using **Add file > Upload files**, then commit.
4. Go to **Settings > Pages**. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, and save.
5. Wait for the Pages deployment. Check the URL shown in Pages settings. For a project repository it normally follows `https://YOUR-GITHUB-USERNAME.github.io/arch-linux-installation/`.
6. Open the live site in a separate browser tab and confirm that all sections, code blocks, and links render correctly.
7. Submit the **working GitHub Pages URL** on Harvey, not a local file path or merely the GitHub repository URL.
8. Keep this guide handy for the separate walkthrough-video deliverable. Verify that SSH, updates, and any optional commands actually worked before demonstrating them.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
